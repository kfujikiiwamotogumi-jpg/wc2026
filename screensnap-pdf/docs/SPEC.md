# ScreenSnap PDF 引き継ぎ書（仕様確定版）

> 2026年6月24日 時点（アップロードされた `.docx` 引き継ぎ書を Markdown 化したもの）

## 0. このアプリは何か（一言で）

「範囲を選択したら、それがそのままPDFになる」ツール。スクリーンショットをいちいち
PDFに変換するのが面倒、という課題を解決する。**撮影 → PDF化を1アクションで完結**させるのが目的。

## 1. 開発の動機・背景

- 画面の一部をPDFにしたいだけなのに、スクショ→画像保存→PDF変換、と手数が多くて面倒。
- 範囲選択するだけでPDFが出来上がれば、その手間がゼロになる。
- ウェブカタログのようなものを、ページごとに同じ大きさで連続キャプチャしたいニーズもある
  （毎回同じ範囲を選ぶのが面倒）。

## 2. 操作フロー（確定）

1. アプリは起動後、タスクトレイに常駐して待機する。
2. 待機中に何かキーを押すと「キャプチャーモード」に入る。
3. キャプチャーモードに入ると、小さな設定ウィンドウが立ち上がる。
4. 画面上には用紙サイズ比率の枠が表示され、マウスに追従して動く
   （サイズ固定モード時はカーソルが消え、枠そのものが動く）。
5. マウスホイールで枠を拡大・縮小する（縦横比は用紙比のまま維持）。
6. 狙った位置で左クリックするとキャプチャ → その場で1枚のPDFとして即保存。
7. 位置を変えて左クリックを繰り返せば、何枚でも連続キャプチャできる。
8. 右クリックすると「終了しますか？」の確認ウィンドウが出て、終了でキャプチャーモードを抜ける。

## 3. キャプチャの2モード

- **モードA：自由ドラッグ** — その都度、好きな範囲をドラッグで選んでキャプチャ。単発・不定形の切り出し向き。
- **モードB：用紙サイズ固定枠（本命）** — 先に用紙サイズを選び、その縦横比の枠でキャプチャ。
  サイズが毎回揃うので、PDFにしたとき全ページ統一感が出る。カーソルが消えて枠が動く →
  ホイールで拡縮 → 左クリックで連発。ウェブカタログの右ページだけを連続で撮る、といった用途に最適。

## 4. 設定パネル（キャプチャーモード中の小ウィンドウ）

キャプチャーモードに入ると立ち上がる。撮りながらその場で切り替え・調整できる。

| 設定項目       | 内容                                                |
| -------------- | --------------------------------------------------- |
| 用紙サイズ     | A4 / A3 / B5 など（ピクセルではなく用紙基準で指定） |
| 向き           | 縦 / 横                                             |
| モード切替     | 用紙サイズ固定枠（モードB） ⇄ 自由ドラッグ（モードA） |
| 保存先フォルダ | 出力先の指定・記憶                                  |

## 5. 保存仕様

- 1枚ずつ、撮った瞬間に即PDF保存（撮るたびにファイルが1つできる）。
- 撮りためて最後に結合、ではなく、その場で1ファイルずつ完結する方式。
- ファイル名は未確定。連番・日時自動が候補。OCRで画像内テキストから取得する案も出たが、
  後回し（オプション扱い）。

## 7. 確定済みポイントまとめ

- コンセプト：範囲選択＝PDF化。手数ゼロが命。
- キャプチャトリガー：左クリック。
- 枠の拡大縮小：マウスホイール。
- キャプチャーモード突入：待機中に任意のキー。
- 終了：右クリック → 確認ウィンドウ → 終了。
- サイズ指定：用紙サイズ（縦横比固定）。
- 保存：1枚ずつ即PDF。
- 設定パネル：キャプチャーモード中に常駐表示。

## 8. 検討中の論点（次回ここから）

### プリンター方式の検討

写真（スクショ）方式は手軽だが、画質が画面解像度どまりで拡大すると粗い。これに対し
「プリンター方式」が論点として浮上した。

- **仮想プリンター方式**：自アプリをWindowsに“プリンター”として登録し、印刷データそのものを
  高精細PDFにする。文字がくっきりし、拡大しても劣化しない。
- ただし範囲選択ができない（ページ全体が対象）、かつプリンタードライバー開発が必要で
  C++など低レイヤー実装になり、難易度が一段上がる。Electronだけでは作れない。

### 両立案（高画質×範囲選択）

- **案1**：プリンターで高精細なページ全体を取り込み → アプリ上で枠を動かして必要部分だけ
  トリミング（高解像度データを切るので劣化なし）。
- **案2**：印刷データをアプリ内に高精細プレビュー表示 → その上でマウス追従の枠＋ホイール拡縮
  ＋左クリックの慣れた操作で切り出す。

### 現実的な進め方（提案）

- **第一段階**：既存の「Microsoft Print to PDF」で一旦PDF化 → そのPDFをアプリにドラッグ&ドロップ
  → 高精細プレビュー → 枠で範囲切り出し。ドライバー開発なしで高画質×自由度を実現できる。
- 使ってみて「毎回手動で印刷するのが面倒」となったら、その時点で仮想プリンター自作に挑戦する。

→ 次回はこの「プリンター方式をどう取り込むか」から再開する。
